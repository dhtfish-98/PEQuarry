# PEQuarry 防御用途与当前复核范围

复核日期：2026-10-06。当前本地候选版本：1.0.7。

## 实际防御用途

检查有权限分析的本地 PE 结构、导入/导出、资源、校验和、静态签名和解析异常，辅助恶意样本静态调查、证据整理及修复复核。库不会装载或执行输入 PE。

## 当前维护与既有实质改写

1.0.7 从公开 1.0.6 精确提交 `011ad5a9badae78e6eb7e1ebc8f714ea61c79036` 继续三项独立窄修复：短 Type 20 调试负载不再中断整个 PE 构造；延迟导入 `phmod` 从本字段而非 `pUnloadIAT` 解码；Guard RF 的两个函数指针在重定位时各更新一次。四个回归检查覆盖完整但从不执行的 PE 文件与文件路径输入。目录声明大小等其他解释语义仍为 OPEN；这不是全算法重写或 Windows 装载一致性声明。当前 1.0.7 仅为本地候选，远端 CI、发行资产与 CVP 资格仍须另行核实。

1.0.6 仅从现行公开 1.0.5 提交 `64e458d08db35fbafce2cdc2e48794a0f306b7dd` 做三项窄修复：2/8 字节 RVA 标量只读取所需长度；负整数（含普通 `int` 子类）标量偏移返回 `None`；目录请求列表按实际存在的数值索引移除全部重复项，缺席项仍保留。对应回归独立覆盖结果、有限内存与列表状态。其他未发布工作不属于此版本的来源。当前仅为本地候选，远端 CI、发行资产及 CVP 资格仍待分别核实。

1.0.5 只移除当前 PEQuarry 配置不可达的旧共用校验分支及其中对无关私有项目的名称引用，更新对应源码清单与发行包版本。PE 运行时解析文件未改；此项不证明旧阶段 3 重写已发表或完整深审通过。历史 Git 对象与 1.0.4 发行资产不因新版本清理而消失。

1.0.4 修复一个有条件的验证器清理风险：在大小写不敏感文件系统上，若直接从含 `Build` 的仓库根目录运行完整 `verify.py`，旧代码可能把生成目录 `build` 解析为 `Build`。现在只匹配真实名为 `build` 的目录项，并拒绝同名符号链接；新增 3 项对应检查。正常 `Build/源码` 暂存与现有 CI 路径未观察到这种删除。该版本没有改动 PE 运行时解析源码，历史自有检查共 319 项。以下 1.0.3 解析改写和 316 项检查为其历史版本范围。

1.0.3 新增资源显式栈、名称与字符串实际跨度、版本父块/UTF-16/翻译字段和相邻记录编辑隔离的实质改写；解析不完整情况有明确标记。历史报告记载 373 项来源观察中 371 项严格相同、2 项精确修正；本次固定干净样本目录实测为 372/370/2，历史多 1 项的具体文件来源仍为 OPEN。旧/新完整修正结果与 Microsoft 格式证据保留在 REVIEWED_VERSION_CHANGES.json。比较工具已修复混合键排序，避免旧 TypeError 遮蔽实际字段。历史版本 316 项自有检查、来源 366 项与当前 364 项通过；2 项旧输出快照为严格登记的预期差异，独立字节验证仍为必过 gate。1.0.2 新增重定位块/条目、动态表、函数覆盖/BDD、异常目录遍历与分阶段展开槽位检查的实质重写：逐记录验证父范围、块进度、字段对齐和实际字节；重复展开信息只登记一次；增加累计记录预算，含不经过结构解码的 RVA 整数和展开槽位。此前已完整重写签名数据库加载和匹配组件；新增有限本地文件读取/写出机制；改写核心输入、静态映射、序列化与校验和；限制原文件内字节编辑跨度，并给结构解码和 `get_data` 设置累计预算。正常离线解析和显式编辑能力保留，来源对照和新增边界测试分别验证。

签名 `filename` 缺失时只报路径错误，不再隐式尝试联网。联网检索改为显式 `load_url`，仅接受无 URL 凭据的 HTTPS、拒绝重定向，限制字节和 socket 等待。该可选入口会发起网络请求，目标授权由调用者提供；普通构造/加载均不联网。本轮联网测试使用模拟响应，没有访问实际签名服务。

显式 `write(filename)` 可覆盖已有普通文件，不是原子操作；拒绝最终链接/FIFO/设备，新文件权限 0600。`write()` 返回序列化字节，不执行样本。完整限制及兼容性改变见 README。

## 未完成范围

其余导入/导出/调试/TLS/绑定导入/配置目录解释、重定位应用、展开操作码/可选链/IA64 语义、结构及别名机制和输出格式仍保留大量来源算法，尚未全部独立重写。输入上限和累计计数不等于全算法 CPU/内存/输出保证。样本运行、Windows 装载、任意恶意格式、所有主机版本和总体超时仍未得到实证。状态保留 OPEN，持续迭代。

静态校验和、熵值和签名匹配不能证明文件安全、来源可信或代码签名有效；来源的 `is_valid`/`is_suspicious` 占位函数仍返回 None，不作为结论。
